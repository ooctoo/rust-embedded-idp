## 1 实施与复用

创建租户沿用既有单接口事务，选择新建账号或已有全局账号作为初始管理员。后续成员、目录、角色与授权仍是独立任务和独立写入，不声称整个准备过程原子提交或自动补偿。

## 2 契约落实

- Enabled 平台会话可准备租户并选择管理目标；目标仅决定管理数据范围，不切换认证会话。Fixed/Choose 非0会话不能借 URL 获得平台操作；Disabled 使用系统域0，不出现租户 CRUD 或已有账号关联入口。
- 初始管理员复用一个创建租户请求的既有事务。已存在邮箱不会覆盖原账号密码，应改选已有用户；已有账号沿用原全局 ID。密码只保留在 Form 内，确认摘要、URL、持久存储和图片不含密码；返回修改、切换来源、提交结束和关闭时清理。
- 确认按操作展示实际 target、business、账号/成员及稳定角色/绑定/权限标识；使用expected_version的操作显示相应版本。租户设置展示读取时的版本快照，以及名称、状态和注册开关的新旧值；创建租户不虚构版本。业务管理员使用 business 范围，覆盖当前及未来有效业务权限，不获得 IDP 管理权，也不需要资源类型/ID。
- 普通角色先读取详情，再显式选择资源类型与 instance/type 范围；初始无默认范围。切换资源类型、范围、角色或业务清除对应旧草稿；instance ID 为既有1–256位字符规则，type 不提交残留 ID。资源存在和归属由宿主业务负责。
- 角色权限采用完整集合替换，保留200项上限与当前版本；移除资源类型的最后一项权限会撤销该类型原分配，之后重新添加不会恢复。目录仅普通业务权限可写，归档后不可修改/复建；系统保护角色使用专用管理员接口。
- grant/revoke 没有角色版本 CAS；确认是快照，实际成员、角色和权限由服务端提交时检查。成员状态、租户、角色、权限说明及归档继续使用各自既有版本；权限启停使用原 `expected_enabled` 状态检查，不增加版本 CAS。409显示通用冲突，不伪造具体领域原因。
- 暂停/移除清理本域 session、refresh、授权码、邮箱验证码和相关选择票据；暂停保留角色与设备绑定，移除另清理本域授权并解绑设备，不删除全局账号。恢复不恢复已退役凭证；重新关联不恢复旧角色/设备绑定。最后有效管理员与账号最后一个未 removed 成员关系的保护规则分开说明，暂停关系也计入后者。
- 本地未发送、明确拒绝、结果未知分别反馈；确认写入后读取失败持续保留已确认结果。未知写入禁止盲重放，须核对原对象。授权恢复锁定原租户/业务/成员/角色/绑定范围，成员 GET 或其他业务读取成功不能解锁；按原范围逐页读到匹配项或末页后显式结束核对。回读只能说明当前状态，不能证明请求归因或密码值。
- 保留 UI-B 的 hash/History、会话 revision、目标 key 和写活动守卫，关闭/重读草稿须确认，处理中禁止离开。窄屏表格局部横滚，确认内容有命名、键盘可聚焦的独立滚动区，初始焦点落取消/返回修改。

## 4 核对与保留边界

本批整合核对修复了原授权恢复可能被普通成员 GET 提前解除的问题、确认层遮住本地错误的问题，以及同值筛选不回首页的问题。成功结果带实际对象/范围；失败回读不保留可编辑的旧角色详情。

精确 `.` / `..` 租户 ID 仍受浏览器 HTTP 路径归一化的旧限制；设置页阻止危险 PATCH，不更改领域标识语法。未知角色删除后 GET 404仍表示不存在或不可见，保留写锁，不能据此认定删除成功；可明确放弃离开并从列表核对。租户创建回读404也不自动解锁或再次创建。账号创建后的邮箱回读不能证明初始密码结果，不自动再次创建。

独立嵌入权限目录的外部宿主仍负责认证生命周期、target/business 属性变更前的离页确认与敏感状态清理；组件按属性 key 隔离本地数据，不新增宿主公共守卫协议。未提供可选 mutation snapshot 的既有客户端适配器，对异常采取保守的“可能已发送”分类。

本地浏览器、构建、隔离数据库证据不代表生产、试点或部署验收；实体设备、Safari、代理/TLS、完整无障碍和所有外部宿主组合均不在本批范围。UI-E–F 的账号安全/设备/会话/审计改造及整体验收未启动，M1-03–06未启动。
