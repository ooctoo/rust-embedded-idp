# CI目标与现有测试覆盖

> 本映射描述当前测试分层和N2退役后的覆盖边界，不代表本轮CI已在远端通过。执行SHA、实际环境与结果见[实施记录](ci-quality-implementation-result.md)。旧N2的逐项清单与运行报告是历史资料，不再是活动测试入口。

## 当前执行层

| 层 | 入口 | 覆盖边界 |
| --- | --- | --- |
| 构建、静态与UT | [ci.yml](../.github/workflows/ci.yml)、Web测试、workspace测试 | 继续覆盖Rust/Web构建、静态检查、业务规则和本地状态；`cargo test --workspace` 不运行 `#[ignore]` 的真实数据库测试。 |
| PostgreSQL/HTTP集成 | [run_live_postgres_checks.sh](../scripts/run_live_postgres_checks.sh)、CI隔离入口 | 通过显式测试URI运行真实适配器、事务和参考宿主HTTP合同；不等同生产数据库升级或部署。 |
| 关键浏览器E2E | [check_ci_e2e.mjs](../scripts/check_ci_e2e.mjs)、[run_ci_e2e.py](../scripts/run_ci_e2e.py)、[ci.yml](../.github/workflows/ci.yml) | 六组固定选集在隔离参考宿主上验证真实用户路径；不等于旧N2全量逐页/排列覆盖。 |

UT和集成的逐项测试名、执行命令与实际通过状态以代码和实施记录为准。历史N2曾包含的配置排列不能反向推定为当前CI覆盖。

## 六组浏览器合同

| 组 | 当前合同 | 与旧N2的关系 |
| --- | --- | --- |
| E01 | 登录拒绝、登录后身份恢复、退出后旧凭据失效 | 迁入关键身份生命周期；旧N2的额外登录页巡检退出。 |
| E02 | enabled/disabled/fixed/choose代表性入口、作用域边界、取消选租户、陈旧目标/迟到响应隔离 | 迁入代表性作用域和过期响应竞态；全量入口、租户及导航排列退出。 |
| E03 | 代表性受保护配置读写回读，以及角色/成员授权的正向和原范围恢复合同 | 从旧授权套件抽取独有权限写入/读取和拒绝越权；完整角色、资源、成员矩阵退出。 |
| E04 | 撤销/危险操作的取消与确认边界 | 保留关键无写入/确认行为；全量确认对话框和页面状态巡检退出。 |
| E05 | 401/403、服务错误和未知写入结果的明确恢复，不静默重放 | 迁入代表性未知结果/安全拒绝；所有错误类型与注入排列退出。 |
| E06 | 双标签刷新协调和独立退出 | 保留修复过的跨标签会话合同；其余多入口/时序排列退出。 |

具体断言以 `scripts/check_ci_e2e.mjs` 及 `scripts/ci_e2e_*.mjs` 为准。本表列出合同类别，不声称覆盖旧N2所有排列，也不把浏览器断言当成真实PG独立证明。

## 集成层责任

- 真实SQL约束、事务/并发、初始化和迁移行为归PostgreSQL集成测试；UT或浏览器中的mock不能替代。
- 身份、用途、租户/业务隔离的核心规则由UT和真实HTTP/存储集成覆盖；浏览器只验证关键交互能穿过这些边界。
- 参考宿主装配、模块路由和typed配置按现有workspace/live测试覆盖。单纯消费者构建不是运行集成证明。
- 迁移工具离线wrapper检查仅证明参数/脚本合同；不宣称所有独立迁移、备份恢复或生产升级均已验证。

## 运行边界

N2旧workflow、驱动、检查器和全量manifest已删除；共享Playwright锁文件、管理页fixture准备、通用进程清理测试保留并服务普通CI。历史执行证据不改写、不删除，只证明各自记录的SHA和环境。

本仓库不再承诺完整N2逐页UI、分页/错误矩阵、所有授权与客户端排列、Mac/Linux环境矩阵、缩放或旁白验收。缩放、旁白和M1-03–06也不属于当前质量范围。若未来需要这些保证，应按独立用户需求重新定义，不默认重建旧编排。
