## 1 上下文、范围与能力复用

详细设计§9.2把UI-F定义为整体核对和回传：汇总UX01–19、复跑受影响Web/嵌入包、编译后真实宿主与隔离数据浏览器任务，并保留未覆盖项。UI-A仍是修订2的设计输入，既有UI-B/C/D/E报告保留各阶段历史，本报告不把静态稿或旧运行记录改称本轮新验收。

继续使用原页面、ManagementClient、会话协调器、hash白名单与离页守卫、`useCursorPage`、ReadState/SafeConfirm及服务端授权/事务。没有修改Rust Core/Axum/存储/参考宿主实现、schema、公开API、配置装配、Cookie协议、token用途、业务入口、嵌入导出或依赖。没有增加MFA、自助恢复、统计、导出、向导补偿或通用幂等层。

## 3 运行环境与证据层级

使用本机已安装镜像`postgres:18.6`，实际PostgreSQL `18.6 (Debian 18.6-1.pgdg13+2)`；不拉取镜像。两mode使用随机独立schema与合成账号，四个仅loopback的编译后Rust宿主覆盖Enabled平台、Fixed非0、Choose和Disabled。API为`/identity`、`/gateway`，UI为`/console`、`/manage`；根mount及browser/UI可选组合由真实宿主测试另行覆盖。

Web先构建，再重新编译宿主并重启本轮自建进程；正常任务不走Vite开发服务器。Node `24.19.0`、pnpm `10.28.2`、Cargo `1.93.0`，使用已有Playwright/Chromium headless shell1243，无新增依赖/下载。仓库约定版本及外部平台兼容不因本机通过而改写。

正常业务及分页走真实HTTP/数据库。UI-F分页通过原API创建51个租户和51个账号；成员随账号创建，设备列表所需51个pending无密钥设备（修订2另增active/disabled各1个排除对照）只在已核对所有权的临时schema中定向SQL播种，不作为设备登记/证明验收。原UI-E设备/终态种子与真实证明的Postgres用例仍分层记录。

异常矩阵的空、403、401、503和迟延为明确浏览器响应注入。加载先取得真实成功body再持有，空页保留真实响应结构后置空items；没有删除启动所需管理client来制造空列表。未知租户创建先真实POST成功，独立原租户/成员/管理员GET确认后才中断页面响应；后续角色503是明确独立失败注入，不冒充实际网络事故。

UI-F与原UI-C–E使用独立夹具，避免51条分页种子改变Choose的首屏成员列表；UI-B与宿主检查亦与这些分页任务分离。不读取仓库`.env`，不连接已有数据库，不清理他人容器或进程。

## 6 检查中发现的问题与调试

实际浏览器确认移动菜单默认回焦覆盖新页标题；实际对比度样本确认Ant默认焦点轮廓不足3:1；嵌套权限确认取消后焦点未回原核对按钮。对应收尾见§2，保留原组件能力，不创建第二套焦点/路由框架。系统管理员搜索页的错误/空表混淆由源码核对定位，并补逐页异常用例。

早期探测先遇到Ant中文二字按钮自动空格及菜单实际名称定位错误；另一次焦点循环把rc-drawer同一弹层的隐藏哨兵误认成离开dialog，已只允许本弹层专用哨兵并保留禁止焦点进入背景的断言。打开动画结束前的焦点检查改为等待组件已接管焦点，不以等待掩盖关闭后回焦失败；嵌套确认的实际缺陷仍由产品修复后验证。

租户恢复脚本最初没有显式接受既有放弃确认，故没有发起预期GET，已修正测试交互。分页候选把设备表中的“待登记”和下拉选项混为定位目标，已限定实际展开选项；等待响应与动作并行持有错误处理，避免关闭上下文的次生错误掩盖原定位错误。平台权限候选最初误用目标域`/access/permissions`，真实源码对Enabled平台使用`/platform/permissions`，已按实际接口修正；平台与目标域状态注入分别执行，没有统一为同一接口。

原UI-B曾在重复使用的夹具校验当前会话时等待超时；另用全新独立夹具完整19组通过。原UI-D有一次键盘选择等待超时，私有诊断副本未改选择断言且完整42组通过，随后未修改的原脚本也完整42组通过；没有把诊断副本或单次部分输出替代原脚本最终结果，也不据超时声称某项产品授权缺陷已修复。视觉核对又发现移动菜单图片截在进入过渡前，补充实际wrapper在视口内、宽度及动画完成检查，并只复跑相同最终资源的无业务写入截图前缀；客户端确认改裁取内容区。截图补验沿用未加入分页数据的独立夹具，避免Choose首屏已变化。此轮没有产品改动，不把图片重制称为又一次82组业务全量运行，完整业务结果与截图补验命令分别记录。

失败尝试不计通过、不归档失败截图/部分JSON。最终完整结果独立记录。

## 8 首轮复跑、清理与核对

先`pnpm --dir web build`，再`cargo build -p embedded-idp-app --locked --offline`和`cargo build -p embedded-idp-storage-postgres --example bootstrap_local_postgres --locked --offline`。使用本机已安装镜像执行`python3 scripts/prepare_management_navigation.py --image <本机Postgres18镜像ID>`，私有state含临时凭证，不打印内容或入库。
